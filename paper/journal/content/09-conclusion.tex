\section{Conclusion}\label{sec:conclusion}
Chunked redaction need not trade correctness for scale. With detector-declared bounds on span length and context, an overlap that covers every detector's span plus its right context makes the streamed result equal to the whole-document result, a seam cross-check makes the parallel result equal to the sequential one, and the working buffer does not grow with the input. Naive and overlapping chunking leaked values that a whole-document pass redacts, on test corpora and real logs alike, while SafeStream's output matched the whole-document output in every chunking tried; memory stayed flat from 8\,MiB to 2\,GiB. These properties remove chunking as a source of leaks; they do not make detection complete. Two detection margins survived cluster-robust resampling and the scanner sensitivity run: more credentials fully redacted than gitleaks, which held on 14,626 real credentials (0.55 against 0.40) at a higher false-alarm rate, and, on a synthetic corpus, higher character F1 than Presidio with the same spaCy model. On real court judgments with independent human gold that second margin reversed for the evaluated configuration; a free-text configuration designed on development judgments and frozen before a held-out run then reached character F1 0.67 against 0.54 for Presidio and fully protected the direct identifiers of 79\% of held-out document--annotator pairs against at most 1\%; unchanged, it also led on character F1 on Wikipedia biographies. In real logs every IP-capable system redacted all IP addresses but none redacted user names, a gap that an opt-in tier built from documented log formats closed on held-out Linux logs. Other margins did not survive, and fewer than one RedactionBench document in five was fully protected by any configuration. The system is therefore suited to reducing exposure in large machine-generated artefacts as one layer among several, and, with the free-text configuration, to a strong first pass over formal prose that a person then reviews; it is not suited to certifying documents for public release on its own. The next steps are free text beyond formal prose and credentials found by a process independent of existing scanners (Section~\ref{sec:plan}).
