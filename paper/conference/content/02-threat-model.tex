Figure~\ref{fig:topology} shows the setting. An agent client relays tool calls chosen by an LLM to a local redaction tool, which reads workspace text and returns replies. We assume the model, its provider or a prompt injected into its context \cite{greshake2023injection} may try to learn values from the workspace, and that it can choose the arguments of tool calls. Everything the tool returns is therefore disclosed. The tool and the host are trusted: an adversary with code execution on the host needs no tool to read a file.

The tool makes two promises. \emph{Content-free replies}: \texttt{scan}, \texttt{explain\_\allowbreak detection}, \texttt{detectors}, \texttt{health}, REST \texttt{/scan} and SARIF output report types, offsets, confidences and detector names, never the matched text. \emph{Redaction}: \texttt{redact} returns the input with every detected value replaced. The first promise can be broken by the implementation; the second is bounded by detection recall. We measure both, and the cost of keeping them.

Out of scope are values the agent could infer from what the tool must disclose by design: the offset and length of a finding, and the suffix shown by masking (Section~\ref{sec:egress} describes what they reveal), and attacks on the model itself \cite{carlini2021extracting,lukas2023pii}.
