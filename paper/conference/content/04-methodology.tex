\section{Method}\label{sec:method}

\paragraph{Protocol} Four research questions, their hypotheses, systems, corpora, metrics and decision rules were committed to the repository before any system was scored. \textbf{C-RQ1}: does the gated neural tier improve person-name detection over T0, and how does it compare with statistical named-entity recognition, at what cost? \textbf{C-RQ2}: how good and how cheap is the gate, and does the tier honour its streaming contract? \textbf{C-RQ3}: does any value reach the agent through a content-free reply, and what does \texttt{redact} leave exposed? \textbf{C-RQ4}: what does the guardrail cost per tool call? \textbf{C-RQ5}, added by a protocol amendment before any third-party tool was installed: do other agent-facing redaction tools let an agent learn the values they protect? \textbf{C-RQ6}, added by a second amendment before any agent run: does a real agent, reading through each tool, take the values back when a prompt injection tells it to? Two later amendments, each committed before its runs, added a second real corpus (BTC) and a second agent model and injection wording, as replications. Every departure is recorded with its reason in the protocol: cost figures come from runs that had the machine to themselves; one throughput comparison has no interval; REST is measured before and after a fix (Section~\ref{sec:cost}); the egress matching rule was tightened after a pilot and both audits repeated (Section~\ref{sec:egress}); one determinism run used a capped stream; and the agent ran on local open-weight models because the study environment could not call a hosted model's API.

\paragraph{Corpora} Table~\ref{tab:corpora} lists the corpora. ai4privacy \cite{ai4privacy300k} is synthetic and was split into halves before this study; only its test half is scored. CoNLL-2003 is the neural model's training distribution and serves as an upper bound only. WNUT-17 \cite{derczynski2017wnut} is the real corpus: human-annotated sentences from Twitter, Reddit, YouTube and StackExchange, grouped into documents of ten sentences in file order, with a manifest frozen with the protocol. The Broad Twitter Corpus (BTC) \cite{derczynski2016btc}, section F (2,000 annotated real tweets, grouped the same way), replicates the WNUT-17 results and was used for nothing else. AgentTrace is generated with a fixed seed. It holds tool output an agent reads (stack traces, \texttt{.env} and YAML files, CI logs, \texttt{git} output, HTTP dumps, tickets) with planted values at known offsets; as its formats come from the rules' authors, it is used only for egress and cost.

\paragraph{Systems} T0 (pattern tiers, Rust core); T0+NN, the product configuration with the gated neural tier; T0+NN ungated, a benchmark-only variant that sends every line, cut into pieces of at most 400 characters, to the model instead of the gate's windows; T0+NN batched (batch 32); T0+spaCy, T0 with spaCy's \texttt{en\_core\_web\_sm} \cite{honnibal2020spacy}; and Presidio \cite{presidio} with spaCy's small and large models. Every system runs single-threaded in its own process.

\paragraph{Metrics and statistics} The primary accuracy metric is person-name character recall: the share of gold person-name characters covered by any prediction, since a redactor protects a name whatever type it assigns. We also report the share of person names fully covered, and character F1 over gold of the types Presidio can detect (``Presidio-scope F1''), so that no system is rewarded for types another cannot emit. Intervals are 95\% percentile bootstrap intervals over documents (2,000 resamples, seed 0). All systems share one resample matrix, so differences are paired, and a planned comparison is called significant when its paired interval excludes zero \cite{efron1993bootstrap}. Cost comes from the same runs: throughput over analysis time (model load excluded), per-document latency, load time and peak resident memory.

\paragraph{Environment} One virtual machine: 4 vCPU Intel Xeon at 2.1\,GHz, Linux, Python 3.13, ONNX Runtime 1.29, spaCy 3.8, Presidio 2.2.366. Each result file records its commit, and the pre-fix measurements ran on the commit before each fix.
