\section{Reproducing the results}\label{app:repro}
Every table and figure is built by \texttt{paper/conference/make\_figures.py} from \texttt{research/results/raw/conf/}. The protocol, with its departures, is \texttt{paper/conference/PROTOCOL.md}; each result file names the commit it ran on. The accuracy grid is \texttt{python -m benchmarks.harness --corpus wnut17 --split test} with the systems of Section~\ref{sec:method}; the gate and context audits are \texttt{benchmarks/gate\_audit.py}; determinism is \texttt{benchmarks/chunking\_leak.py --onnx}; egress is \texttt{benchmarks/mcp\_egress\_audit.py}; residual exposure, transport latency and redaction-mode cost are \texttt{benchmarks/residual\_exposure.py}, \texttt{mcp\_latency.py} and \texttt{policy\_overhead.py}.
