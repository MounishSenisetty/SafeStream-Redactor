Endpoints: GET /health, /version, /detectors,
        POST /redact, and POST /scan, which returns offsets and types but never the matched text.

    


    
    

      
safestream mcp-serve gives an AI agent redaction tools over the
        Model Context Protocol. The tools report what was found and where,
        never the secret itself. Send the same JSON-RPC messages an agent would.

Connect your MCP client

        
Install the package, then add this to your client's configuration (Claude Desktop, Cursor, and others):

        
{
  "mcpServers": {
    "safestream": { "command": "safestream", "args": ["mcp-serve"] }
  }
}

pip install safestream-redactor

Command line

          
safestream redact app.log -o clean.log
safestream detect src/ --fail-on-detect
tail -f app.log | safestream redact - -o -

        

        

          
Python

          
from safestream_redactor import Redactor

Redactor().redact_file("huge.log", "clean.log")

        

        

          
Docker

          
docker run --rm --network none -v "$PWD":/data \
  ghcr.io/mounishsenisetty/safestream-redactor \
  redact /data/app.log -o /data/clean.log
