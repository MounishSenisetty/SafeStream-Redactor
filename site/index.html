    Memory stays flat as input grows
    
        
    Generate a synthetic service log of each size inside the engine and stream it
          through redact_stream, as safestream redact streams a file. Each size
          runs twice: once timed, once under Python's tracemalloc
          to measure the peak memory the engine allocates. The log is generated as it is read and the
          output is hashed as it is written, so neither is ever held whole.

    How it works
    
      
      
        
    1. Stream through a fixed window. Text is read in chunks into a rolling buffer of one chunk plus
          an 8 KiB overlap. Only text at least one overlap from the end of the buffer is written each round; the rest is
          carried into the next, so an entity cut by a chunk boundary is still seen whole. Memory never grows with input size.
      2. 
        
    2. Detect in tiers. Patterns with validators (Luhn, SSN rules, …), entropy scoring for unknown
          secrets, and optional NER (spaCy or ONNX) find candidates; contextual scoring, a confidence filter and overlap
          resolution decide what is kept.
      3. 
        
    3. Rewrite by policy. Each kept span is replaced: replace, mask, pseudonymize, hash, encrypt or
          fictionalize. Everything outside a redacted span, line endings included, comes out byte for byte as it went in.
      4. 
      
    
      
    
        
     text chunks ──> [ rolling buffer: chunk + 8 KiB overlap ] ──> redacted chunks
                                   │
          ┌────────────────────────┼─────────────────────────┐
          ▼                        ▼                         ▼
   patterns + validators     entropy scoring          NER (optional)
   (Luhn, SSN rules, …)      for unknown secrets      spaCy or ONNX
          └────────────────────────┼─────────────────────────┘
                                   ▼
            contextual scoring ─> confidence filter ─> overlap resolution
                                   ▼
        redaction policy: replace, mask, pseudonymize, hash, encrypt, fictionalize
    
        
    From the README. In this page the NER tier is not available (see Install → Not in this browser demo).
    
      
    

      
    
        
    
          
    Limitations
    
          
    No tool can guarantee every name or free-form identifier in prose is found: "April" is a name and a month,
            and an account number looks like any other run of digits. SafeStream is tuned for high precision on structured
            PII and credentials. For names, enable [ner] or [onnx]. For identifiers without a fixed
            format, add label-anchored patterns, as in examples/policy.toml. Review redacted output before
            sharing it anywhere a miss would be costly.
    
          
    Where it loses, from the README's evaluation: Presidio's transformer engine redacts more entities fully, and
            wins on ai4privacy. SafeStream misses values inside structured fields, unlabelled ID numbers, many international
            phone formats, and many names.
    
        
    
        
    
          
    This demo, specifically
    
          
      
            
    • Text typed or dropped here is capped at 1 MiB; the CLI streams files of any size.
      • 
            
    • It runs the pure-Python engine on one thread inside WebAssembly, slower than a local install.
      • 
            
    • The spaCy and ONNX name tiers, encrypt mode, the native core, multi-core workers and kernel-enforced offline
              mode need your machine (Install tab).
      • 
            
    • The in-process network guard is defence in depth, not a sandbox. Locally, --offline-hard on Linux
              or docker run --network none adds a hard boundary.
